# TASK-003 — Редизайн: Конверсионный сайт без тяжёлого 3D

**Статус:** PENDING  
**Приоритет:** P0 — полная смена направления  
**Дата:** 2026-04-11  
**Инициатор:** Олег (владелец)

---

## Решение

После нескольких итераций с Three.js/WebGL сферой — **отказываемся от тяжёлого 3D**.

**Причина:** сложная 3D сцена требует времени, но не продаёт. Цель сайта — конверсия, не демо WebGL.

**Новое направление:**
- Лёгкие CSS/Framer Motion анимации вместо WebGL
- Чистый, дорогой дизайн (тёмная тема, космическая атмосфера через градиенты + типографику)
- AI-ассистент Юра — главный продавец, финальный закрыватель
- Каждая секция ведёт к одной цели: **заявка**

---

## Стек визуала (без WebGL)

```
Фон:         CSS radial-gradient + noise texture + редкие CSS-частицы (canvas 2D или CSS pseudo)
Hero анимации: Framer Motion (stagger, scroll-triggered)
Акценты:     CSS glow (filter: drop-shadow), border animations
Карточки:    glassmorphism (.glass класс уже есть)
Иконки услуг: SVG иконки / emoji-планеты через CSS (не Three.js)
```

**Допускается:** лёгкий canvas 2D для звёздного фона (< 2KB кода, 0 библиотек)

## Полная структура страницы (воронка)

### 1. Navbar
- Логотип OPTISPHERE (Orbitron)
- Ссылки: Услуги / Портфолио / Цены / Контакт
- Переключатель RU/EN
- CTA кнопка "Обсудить проект"
- Mobile: бургер

### 2. Hero — WOW + УТП (выше сгиба)
**Цель:** за 3 секунды объяснить кто мы и зачем

Layout:
- Left 55%: H1 + subtitle + CTA кнопки
- Right 45%: визуальный акцент (CSS animated glow sphere / gradient orb)

Текст:
- H1: "Сайты, которые приносят клиентов" (Orbitron, огромный)
- Sub: "Разрабатываем продающие сайты, панорамы 360° и настраиваем продвижение. Работаем на результат."
- CTA1: "Обсудить проект" (primary button)
- CTA2: "Рассчитать стоимость" (outline)
- Stat strip: 25+ проектов | 97% довольных | 3–7 дней

Визуал справа:
- Большой CSS orb: radial-gradient синий/фиолетовый, animated pulse
- 4 плавающих мини-карточки вокруг (услуги), Framer Motion float animation
- Или: просто крутой типографический блок с кодом / метриками

### 3. Services — 4 услуги
**Цель:** понять что именно делаем, захотеть

4 секции / карточки:
- **Сайты** (#4F8EFF) — START/PRO/PREMIUM, от 50к
- **Панорамы 360°** (#C9A96E) — для гостиниц/апартаментов, от 8к/объект
- **Продвижение** (#3ECFA0) — SEO + Яндекс.Директ, часть подписки
- **Подписка "Орбита"** (#A78BFA) — ежемесячно, 10–25к

Варианты layout:
- Горизонтальный скролл (горизонтальные карточки) — как планеты в солнечной системе
- Или 2×2 grid с hover reveal деталей

### 4. Portfolio — кейсы с цифрами
**Цель:** доверие

- Фильтр по категории (Сайты / Панорамы / Продвижение)
- Карточки: скриншот + название + ключевые цифры ("+40% конверсия")
- ПОКА: заглушки с реальными категориями
- CTA: "Хочу такой же"

### 5. Calculator — интерактивный расчёт
**Цель:** вовлечение + квалификация + передача Юре

- Тип сайта: лендинг / продающий / кастом
- Функции: галерея, форма, личный кабинет...
- Срочность: стандарт / ускоренный
- → Показывает диапазон: "60–120 000 ₽, 5–8 дней"
- → После результата: появляется Юра с "Хочешь уточним под твой проект?"

### 6. Orbit Subscription — выделенный блок
**Цель:** конвертировать в ежемесячного клиента

- 3 тарифа: START 10к / PRO 15к / MAX 25к
- Что входит — чеклист
- "Сейчас 3 места из 10"

### 7. Trust — доверие
- 3–5 кейсов с цифрами
- Логотипы клиентов (стилизованы)
- Отзывы

### 8. Contact — форма заявки
- Имя + Telegram/телефон + комментарий
- POST /api/leads/telegram → отправка в TG бот Олега
- После отправки: "Юра получил заявку и скоро напишет"

### 9. Юра — AI ассистент (ГЛАВНЫЙ ПРОДАВЕЦ)
**Это самый важный компонент.**

Поведение:
- Появляется через 15с или после 40% скролла — НЕ сразу
- Trigger: после калькулятора — активируется автоматически
- Роль: консультант → квалификатор → продавец → закрыватель
- Скрипт: 1–2 вопроса → польза → помощь → "Как лучше связаться?"
- Финальная реплика: "Ну что, делаем?" (прямо, без лишнего)
- Иногда говорит факт о космосе — характер, не скрипт
- Получает контакт → отправляет в Telegram (диалог + summary + intent)

Техника:
- API route: POST /api/ai/chat (streaming SSE)
- Claude API: claude-haiku-4-5 (скорость) / claude-sonnet-4-6 (качество)
- System prompt: роль Юры, контекст услуг, цены, скрипт продажи
- Визуал: стеклянная сфера / energy bubble, внизу справа

### 10. Footer
- Логотип + краткое описание
- Ссылки
- Соцсети / Telegram
- ©
