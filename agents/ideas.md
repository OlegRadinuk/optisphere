## 🔴 Крупные проекты (> 1 дня)

- [ ] [2026-04-30] **Надёжность БД — приоритет #1 системы**
  SQLite WAL накапливается и корраптит БД при неправильном завершении PM2.
  Нужно:
  - WAL auto-checkpoint по размеру (каждые 1000 страниц)
  - Принудительный PRAGMA wal_checkpoint(TRUNCATE) перед остановкой
  - PM2 graceful shutdown hook
  - Ежедневный бэкап bots.db на сервере с ротацией (7 дней)
  - Тест: sqlite3 integrity_check в deploy.sh, если плохо — не деплоить

- [ ] [2026-04-30] **Мониторинг-дашборд в админке**
  Отдельный раздел в /aiadmin: статус каждого бота в реальном времени.
  - Зелёный/жёлтый/красный индикатор по каждому боту
  - Последний health-check: когда, ответил ли осмысленно
  - context_url: доступен / последний успешный fetch
  - Количество диалогов за 24ч / 7д
  - Алерт если бот не ответил > 5 минут
  - Алерт если context_url недоступен > 15 минут
  Цель: всё видно с одного экрана, без SSH и логов.

- [ ] [2026-04-30] **Health-check + Self-healing**
  Каждые 10 минут — автоматический тестовый диалог с каждым ботом.
  Проверяет: ответ пришёл, не пустой, не "ошибка соединения".
  При сбое: уведомление в Telegram немедленно.
  Self-healing: если бот не отвечает — автоматический pm2 restart,
  повторная проверка через 2 минуты, алерт если не поднялся.
  Реализация: отдельный cron-сервис или UptimeRobot с кастомным HTTP-монитором.



- [ ] [2026-04-30] **AI-first позиционирование — первая крымская AI-first компания**
  Стратегия: Optisphere = не просто веб-студия, а AI-first компания в Крыму.
  Отдельная страница по созданию AI-ассистентов (детальная, с кейсами, техническими деталями, ценами).
  Отдельная страница по созданию сайтов (аналогично).
  Все маркетинговые материалы вокруг тезиса "первая AI-first компания в Крыму".

- [ ] [2026-04-30] **Страница /demo — живые демо всех AI-ботов**
  Три варианта реализации (все три в итоге):
  1. **Карточки с живыми виджетами** — страница `/demo` с карточками клиентов (логотип, ниша, описание).
     Кнопка "Поговорить" открывает виджет конкретного бота прямо на странице.
  2. **Секция на главной** — блок "Наши боты в действии", 3-4 карточки, разворачивается чат по клику.
     Иммерсивно, прямо в потоке прокрутки главной.
  3. **Полноценная страница с фильтрами** — `/assistants` с фильтрацией по нише (медицина / туризм / строительство).
     У каждого бота: кейс + живой чат + результаты. Растёт с портфелем.
  Технически: widget.js переписать на **Shadow DOM** — каждый экземпляр живёт в изолированном дереве,
  стили и JS не конфликтуют. Делать в первую очередь, до страницы /demo.
  Один `<script data-bot="slug">` = один независимый виджет. Так делают Intercom, Crisp, HubSpot.
