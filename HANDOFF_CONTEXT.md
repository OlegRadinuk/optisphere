## Что строим
Один сайт (не два). Главный оффер — ИИ-ассистент как продукт.
Панорамы, сайты, продвижение — это услуги внутри, не отдельные продукты.

Стек: Next.js + Node.js. Проект уже начат, есть существующий код.

## Требования к сайту
- Продающий, не портфолио
- Motion-дизайн кинематографического уровня:
  - Scroll-driven storytelling (секции появляются как кадры фильма)
  - Видео/canvas привязанное к скроллу
  - Cinematic enter animations (stagger, clip-path wipe, parallax)
  - 3D элементы через Three.js / R3F
  - Lenis smooth scroll + magnetic кнопки
- Живой ИИ-ассистент прямо на главной — это главный WOW-момент
- Библиотеки: GSAP + ScrollTrigger, Framer Motion, Three.js/R3F, Lenis

## Система агентов (что уже спроектировано)

### Архитектура файлов
```
~/.claude/AGENTS.md              ← глобальный оркестратор (все проекты)

project/
├── AGENTS.md                    ← локальный контекст проекта
└── .claude/
    ├── agents/
    │   ├── planner.md           ← декомпозиция задач
    │   ├── designer.md          ← motion-first UX/UI
    │   ├── frontend.md          ← cinematic components
    │   ├── backend.md           ← API / DB
    │   ├── security.md          ← ревью
    │   └── qa.md                ← тесты
    ├── context/
    │   └── state.json           ← единый стейт проекта
    └── artifacts/               ← JSON вывод агентов
```

### Принципы экономии токенов
1. Оркестратор хранит полный стейт, агентам передаёт только свой slice
2. Агенты общаются через JSON артефакты, не текст
3. Каждый агент получает только контекст своей области
4. Prompt caching для системных промптов агентов
5. Поле `next_agent` в выводе — агенты сами маршрутизируют цепочку

### Режимы оркестратора
- SOLO: одна задача → один агент
- CHAIN: цепочка designer → frontend → backend → security → qa
- PARALLEL: frontend + backend одновременно, потом security

### Context7
Оркестратор вызывает Context7 перед каждым агентом чтобы подтянуть
актуальную документацию GSAP, Framer Motion, Three.js, Lenis.

- Пройтись по всем .md файлам агентов
- Убедиться что designer и frontend имеют motion-ДНК (scroll storytelling, cinematic enters, 3D)
- Убедиться что оркестратор умеет SOLO / CHAIN / PARALLEL режимы
- Проверить интеграцию Context7

### 2. Посмотреть текущий код сайта

### 4. Pre-mortem агент (отложено, но не забыто)

## Ключевые инсайты из нашего разговора
- Проблема прошлых итераций: не было чёткого оффера → агент строил "что-то красивое"
- Motion-дизайн это упаковка, оффер первичен
- Живой ассистент на главной = лучший WOW-момент, лучше любой анимации
- Два сайта не нужны — один сайт, один главный месседж
- ИИ генерирует лиды, нужен чёткий путь клиента до оплаты
