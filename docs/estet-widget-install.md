# Установка AI-ассистента «Яна» на сайт dentalestet.ru

## Что это

Виджет чат-бота, который появляется на сайте и отвечает на вопросы пациентов:
цены, услуги, запись на приём. Работает круглосуточно.

## Установка — 1 шаг

Вставьте один тег перед закрывающим `</body>` на **каждой странице** сайта:

```html
<script src="https://optisphere.tech/widget.js" data-bot="estet" data-greeting-delay="10000"></script>
```

Больше ничего не нужно. Виджет подгружается сам, стили не конфликтуют со страницей.

`data-greeting-delay="10000"` — виджет появляется через 10 секунд после загрузки страницы (значение в миллисекундах).

## Проверка

После вставки откройте любую страницу сайта — через 10 секунд в правом нижнем углу
появится кнопка чата с именем **«Яна»**. Напишите «сколько стоит пломба?» —
бот должен ответить с ценами.

## Если используется CMS или шаблонизатор

Вставьте тег в общий footer-шаблон — он автоматически появится на всех страницах.
